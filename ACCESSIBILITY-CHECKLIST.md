# Checklist accessibilité

- [x] Langue de chaque page déclarée.
- [x] Un H1 unique par page principale.
- [x] Lien d'évitement.
- [x] Navigation clavier et focus visible.
- [x] Mise en page responsive jusqu'à 320 px.
- [x] Images avec alternatives textuelles pertinentes.
- [x] Graphiques accompagnés de valeurs textuelles/tableaux.
- [x] Formulaires avec labels explicites, champs obligatoires et validation native.
- [x] Pas d'information portée uniquement par la couleur.
- [x] `prefers-reduced-motion`.
- [x] Liens de langue page-à-page FR/EN.
- [ ] Audit humain complet RGAA / WCAG avec NVDA, VoiceOver et navigation clavier à réaliser avant toute revendication de conformité totale.
