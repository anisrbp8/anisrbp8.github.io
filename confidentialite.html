Accueil / Confidentialité

Confidentialité

Confidentialité et données du site

Ce site présente mes activités universitaires. Il ne comporte ni publicité ni outil de profilage.

Contact

La page de contact permet de m’envoyer un message au moyen du service Formspree. Les données saisies — nom, adresse électronique, organisme éventuel, objet et message — sont transmises à ce service pour acheminer votre demande. Consultez la politique de confidentialité de Formspree (en anglais) pour connaître ses modalités de traitement. Évitez les informations sensibles qui ne sont pas nécessaires à votre demande.

Hébergement

Ce site est hébergé sur GitHub Pages. GitHub décrit le traitement des données techniques dans sa déclaration de confidentialité.

Cookies et mesure d’audience

Les pages ne chargent aucun script de mesure d’audience ou de publicité. Les réglages de lecture utilisent le stockage local du navigateur.

Liens externes

Les figures et leurs agrandissements sont hébergés sur ce site. Si vous suivez un lien vers un éditeur, une université ou un profil scientifique, le site que vous ouvrez applique sa propre politique de confidentialité.

Préférences de lecture

Les préférences de lecture sont enregistrées localement dans votre navigateur, afin d’être conservées d’une page à l’autre. Elles ne sont pas transmises au serveur du site. Le bouton de réinitialisation les efface.
