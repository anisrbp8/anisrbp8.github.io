- Source : https://www.univ-paris8.fr/IMG/png/logo_paris8_noir.png

- Crédit : © Université Paris 8. Le fichier conserve les conditions d’utilisation de l’université ; il n’est pas placé sous licence libre par ce dépôt.
- Affichage : version monochrome noire sur fond blanc, avec espace de protection ; aucune recoloration ou déformation. Le fond blanc est conservé dans les préférences de lecture sombres.
- Intégration le 15 novembre 2026, après confirmation de l’autorisation d’usage par le propriétaire du site.

## Aperçus de partage

- `anis-rojbi-social-fr.png` et `anis-rojbi-social-en.png` : cartes de partage de 1 200 × 630 pixels, avec leur source SVG correspondante.
- Les trois premiers domaines suivent la hiérarchie du site : accessibilité numérique, traitement du signal et des images, technologies d’assistance.
- Le portrait source `anis-rojbi-920.jpg` est intégré sans retouche. Les textes français et anglais restent modifiables dans `scripts/build_social_cards.py`.
- Reconstruction : `python3 scripts/build_social_cards.py` (Inkscape requis).
