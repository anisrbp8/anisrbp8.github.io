Accessibility

Accessibility statement and design principles

Accessibility improvements and transparent assessment status.

Accessibility status

Full conformance has not been established. This website is being assessed against France’s RGAA 4.1.2 and WCAG 2.2 levels A and AA, with additional applicable AAA requirements. Automated results do not establish conformance on their own.

Available features

  • Keyboard navigation, a skip link and visible focus.
  • Reading preferences for colours, text size and spacing.
  • Text alternatives for images and text values for charts.
  • Full HTML versions of the CV and biography.
  • A simple overview, a glossary and a site map.

Assessment scope

The review covers all French and English HTML pages, navigation, styles, scripts and the four downloadable documents. Automated checks cover selected WCAG rules and layout behaviour at desktop and narrow widths. They are complemented by code review and keyboard checks.

Checks still requiring human validation

Testing with screen readers and users is needed to validate actual reading order, pronunciation, alternative-text quality and ease of use. PDF structure and reading order require a dedicated document audit. Plain-language summaries have not been certified as Easy Read.

Report an accessibility problem

Use the contact page. Please identify the page, the difficulty encountered and, if possible, your browser and assistive technology. You can also request the information in another format.

Reference standards

  • RGAA 4.1.2: criteria and tests (French)
  • WCAG 2.2
